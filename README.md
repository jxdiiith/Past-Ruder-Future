# Past Ruder Future
Past Ruder Future is an interactive performance that connects analogue printing techniques with the digital world and explores the themes of past and future. It presents the specimen of the typeface Ruder Plakat Var by Lineto. A question is printed by hand with 3D-printed stamps. A camera tracks the movements of the people stamping and uses this information to change the variable font on screen. Meanwhile the AI (Gemini) comments on the process. Once the question is complete the AI generates an answer.

For this to work you need to put your own API key in the .env file. You also need to install node.js, the server here in visual studio code then can be started with "node server.js"
